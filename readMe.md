# Gushwork Frontend Assignment

A responsive industrial product landing page built using Vanilla HTML, CSS, and JavaScript based on the provided Figma design.

## Project Overview

This project was developed as part of the Gushwork frontend assignment.

The implementation focuses on:
- Pixel-perfect UI development
- Responsive design
- Interactive user experience
- Scalable DOM rendering
- Clean and maintainable frontend architecture

The page is fully responsive across:
- Desktop
- Tablet
- Mobile devices

---

## Assignment Requirements Implemented

### Sticky Header
- Sticky header appears after scrolling beyond the first fold
- Smooth transition animations
- Automatically hides when scrolling back up

### Image Carousel with Zoom
- Interactive image carousel
- Previous/Next navigation
- Thumbnail selection
- Hover zoom preview functionality
- Smooth transitions and interactions

### Responsive Design
- Fully responsive layout
- Flexbox and CSS Grid used where appropriate
- Optimized spacing and scaling across devices

---

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6)

---

## Development Approach

The project follows a data-driven rendering approach where multiple sections are generated dynamically using JavaScript arrays and objects instead of hardcoded repetitive HTML.

This approach improves:
- Scalability
- Reusability
- Maintainability
- Separation of concerns

Reusable rendering patterns were implemented for:
- Cards
- FAQ items
- Carousel items
- Specifications
- Testimonials
- Modals
